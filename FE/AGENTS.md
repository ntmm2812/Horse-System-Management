# Hướng dẫn Phát triển & Quy tắc Dự án

## Tổng quan
Dự án: **Mã Phong — Hệ thống Quản lý Huấn luyện Ngựa đua Chuyên nghiệp** (Race Stable Hub).

## Cấu trúc Tech Stack
- **Framework**: React 19 + TanStack Start (Router, SSR, Server Functions)
- **Styling**: Tailwind CSS v4 + Lucide React
- **Biểu đồ**: Recharts
- **Database / Backend**: Supabase (Client & Server Admin Client)
- **Công cụ phát triển**: Vite + TypeScript

## Quy tắc Code
- Duy trì cấu trúc thư mục rõ ràng theo quy chuẩn TanStack Start và React.
- Giữ giao diện hiện đại, chuyên nghiệp, responsive và thân thiện với người dùng.
